# Vita Test — iPhone

Изолированный публичный репозиторий для тестирования интерфейса Vita на iPhone.

**Без реальных данных.** Не использовать рабочие резервные копии, токены, персональные или финансовые записи.

Рабочая Vita, закрытый исходный репозиторий и Railway не изменяются.

Публикация GitHub Pages будет включена только после проверки тестовой сборки на секреты, персональную информацию, внешние запросы и безопасность хранения данных.
