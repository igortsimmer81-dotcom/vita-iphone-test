# Vita Test 2.0 — единый журнал

## Реализовано в тестовой ветке main
- Фиксация модальных панелей по ширине экрана, отключение горизонтального скролла и горизонтальных жестов внутри модалок.
- Обзор «Мои дела»: Просрочено, Сегодня, Без даты, Предстоящие; прежние фильтры доступны через выбор дня.
- После создания задачи в Календаре — обзор всех задач.
- Иконка сбережений: линейный знак $ без окружности.

## Требует проверки непосредственно на iPhone
- Все формы (поставщики, оплата, долги, инвестиции, сбережения, настройки): фиксация, клавиатура, длинные формы, доступ к кнопкам.
- Создание задач с датой и без даты, редактирование, выполнение.
- Сбережения, резервное копирование только вымышленных тестовых данных.

## Отложено / не реализовано
- Push: отдельный независимый сервер, Service Worker и разрешения; работающая Vita и Railway не используются. Нельзя обещать доставку до настоящего end-to-end теста.
- Пользовательская иконка приложения: ожидаем эскиз.
- Пересмотр крупных карточек главной, компактность поставщиков/долгов/инвестиций и безопасность удаления: требуется отдельная проверка взаимодействий.
- Категория «Недвижимость» вместо «Продукты»: согласовать изменение справочника категорий перед правкой.

## Неприкосновенно
Никаких реальных финансовых данных, действующих токенов, рабочей Vita, production Railway, production ключей хранения. Резервная ветка перед изменениями: backup/before-vita-test-2-ui.
