# VITA COSMIC MAC — функциональный календарь

Дата: 2026-11-04
Ветка: `feature/vita-cosmic-mac-integration`
Файл: `index.html`
Статус: готово к проверке в браузере; production не менялся.

## Интеграция

В существующей тестовой Vita раздел `tasks` на Mac (экран от 1024 px и мышь/трекпад) получает двухколоночный интерфейс календаря:
- месячная сетка с выбранной датой, переходами между месяцами и возвращением к сегодняшней дате;
- точки дней с активными задачами, приглушённая розовая подсветка просрочек;
- просмотр задач за день, неделю, месяц и выполненных задач;
- справа отдельный раскрытый список невыполненных просроченных задач;
- кнопка «+ Добавить задачу», открывающая существующую форму `openForm('task')`; выбранная дата предварительно подставляется в форму;
- вывод записей через существующую `taskRow`, поэтому редактирование и отметка выполнения используют существующие `editTask` / `toggleTask`.

Существующие `addTask`, `editTask`, `toggleTask`, `save`, функции напоминаний, модель данных и ключ `vita_iphone_test_demo_v1` не изменялись.

В мобильном интерфейсе остаётся исходное представление `views.tasks` (через проверку `matchMedia`).

## Проверено

- JavaScript нового скрипта успешно проходит проверку синтаксиса.
- В изолированном имитационном запуске рендерится месячная сетка; просроченная запись выделяется; отображение «Готово» содержит выполненную запись; нажатие «Добавить задачу» открывает существующую форму и заполняет дату.
- Ветки просмотра день/месяц/готово протестированы имитационным набором задач.
- Изменения хранятся в отдельной ветке GitHub и не переносились в `main`, Railway или действующую Vita.

## Нужно проверить на Mac до переноса

1. Открыть тестовую сборку именно этой ветки (не GitHub Pages `main`).
2. Добавить вымышленную задачу, перезагрузить страницу, сверить сохранение и обе панели.
3. Редактировать задачу, отметить выполнение, проверить «Готово» и просрочки.
4. Проверить MacBook в обычном окне и при изменении ширины; версию iPhone проверить отдельно.
5. Проверить существующую логику уведомлений и экспорт/импорт на тестовых данных.
6. Проверить, что источник кода текущей Mac Vita действительно совпадает с ожидаемой тестовой архитектурой, прежде чем готовить перенос в production.

## Ограничения

- Подключение к настоящим финансовым данным запрещено.
- Это визуальная интеграция с существующими тестовыми функциями, не синхронизация Mac/iPhone.
- Браузерная отрисовка самой ветки пока не подтверждена; успешное развёртывание не заявляется.
